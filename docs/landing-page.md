Design a **premium, high-converting landing page** for a modern AI-powered software development project management platform.

The product combines:

* AI-assisted task creation
* AI-assisted requirements
* Kanban project management
* Sprint planning
* Team collaboration
* Documentation
* GitHub integration
* AI code review
* Analytics

The landing page should make developers, engineering teams, and product managers immediately understand the value and want to try the product.

Build it using:

* React + TypeScript
* Tailwind CSS
* shadcn/ui
* Lucide React icons
* Responsive design
* Light + dark mode

# VISUAL STYLE

Make this feel like a **top-tier developer SaaS startup**.

Design references:

* Linear
* Vercel
* Raycast
* GitHub
* Notion

Do NOT copy them.

Create a unique identity.

Use:

* Strong typography
* Large confident headlines
* Subtle grid/background patterns
* Minimal gradients
* Soft borders
* Beautiful dark sections
* Carefully designed product screenshots
* shadcn/ui components
* Smooth hover animations
* Scroll-based subtle animations
* Excellent spacing

Avoid:

* Generic stock illustrations
* Fake testimonials
* Fake customer statistics
* Excessive gradients
* Excessive glassmorphism
* Huge meaningless graphics
* Marketing buzzwords without explanation
